# GoldLeafView

<Subtitle>a feed card</Subtitle>

A Gold Leaf can display either an RSS post or an email which is an article that we have emailed ourselves to read later.

```jsx

const goldLeafModel = PortholeBranchModel | EmailModel;

<GoldLeafView variant="email|article" goldLeafModel={goldLeafModel} />
```
