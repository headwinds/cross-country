# Branches

This is the RSS Feed Branches component that powers [golds](https://golds.vercel.app).

```jsx
const onLoadedCallback = (error) => {
  console.log(error.message);
};

const feedUrl = "http://localhost:5000/api/porthole/trees";

const sampleUrls = [
  "https://coolhunting.com/feed/",
  "http://kotaku.com/rss/vip",
  "http://feeds.feedburner.com/colossal",
  "http://feeds.feedburner.com/design-milk",
];  

<Branches onLoadedCallback={onLoadedCallback} feedUrl={feedUrl} urls={sampleUrls} />;
```
