# Take

`TakeAnswerInput` allows a user to enter a text answer to a question in a single row which is ideal for pasting in a url.


### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| data | any | Yes | The input data to be displayed and modified |
| onChange | (data: any) => void | Yes | Callback function triggered when data changes |
| customClass | string | No | Custom CSS class for styling the component |
| hasSave | boolean | No | Whether to display a save option/button |
| variant | "date-time", "text", "multiple-choice" | No | Type of input to display (text or date-time) |
| placeholder | string | No | Placeholder text for the input field |
| selectedId | string | No | ID of the currently selected item if applicable |
