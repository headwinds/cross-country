# Button

This is the start for a new Button story. I'm missing quite a lot right now.

What should go in a button story? Obviously one of (if not _the_) most important UI elements!

A Button needs to be able to render the following states:

- default
- hover
- active
- disabled

And for accessibility, it should be able to render the following types:

- primary
- secondary

We need to be able to distinguish between primary and secondary buttons for users who are color blind.

And for extra flare and to attract attention, we can consider animation and sound effects (thanks to [use-sound](https://www.joshwcomeau.com/react/announcing-use-sound-react-hook/) )

```jsx

import retro from '@/assets/sounds/retro.mp3'; // .wav, .mp3, .ogg, etc

const onClick = () => {
  console.log('clicked');
}


<Button onClick={onClick} sound={retro}>click me</Button>
```
